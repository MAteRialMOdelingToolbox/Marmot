Interface Finite Element

Theory

The interface element models a zero-thickness interface between two bodies, or between two parts of one body, by means of the displacement jump across it. The element has \(2 n\) nodes: the first \(n\) nodes form the bottom side and the last \(n\) nodes the top side of the interface, so that the element is described by one surface of \(n\) nodes in the reference configuration. The kinematics are small-deformation (linearized).

At each quadrature point of the interface surface, the element evaluates the shape functions \(\mathbf{N}\) of one side, the surface metric, the unit normal \(\mathbf{n}\), and the surface gradient operator \(\mathbf{B}_s\) of one side. The two sides are combined into the operators

\[[\![\mathbf{u}]\!] = \mathbf{u}^{+} - \mathbf{u}^{-} = \mathbf{N}_{\mathrm{jump}}\, \mathbf{q}, \qquad \mathbf{N}_{\mathrm{jump}} = \big[\, -\mathbf{N} \;\; +\mathbf{N} \,\big],\]
\[\bar{\nabla}_s \mathbf{u} = \tfrac{1}{2}\big( \nabla_s \mathbf{u}^{-} + \nabla_s \mathbf{u}^{+} \big) = \mathbf{B}_{\mathrm{avg}}\, \mathbf{q}, \qquad \mathbf{B}_{\mathrm{avg}} = \tfrac{1}{2}\big[\, \mathbf{B}_s \;\; \mathbf{B}_s \,\big],\]

where \(\mathbf{q}\) is the vector of nodal displacements.

The constitutive response is provided by the interface material. Per quadrature point, the material receives the increments of the jump and of the surface gradient, and it returns the force \(\mathbf{t}\) (conjugate to the jump), the surface stress \(\mathbf{s}\) (conjugate to the average surface gradient), and the tangent operators \(\mathbf{Q}\), \(\mathbb{Z}\), \(\mathbf{H}\) and \(\mathbb{Y}\).

The element internal force vector and the tangent stiffness are

\[\mathbf{P}_e = \sum_{qp} \Big( \mathbf{N}_{\mathrm{jump}}^\mathsf{T}\, \mathbf{t} + \mathbf{B}_{\mathrm{avg}}^\mathsf{T}\, \mathbf{s} \Big)\, J_0\, w,\]
\[\mathbf{K}_e = \sum_{qp} \Big( \mathbf{N}_{\mathrm{jump}}^\mathsf{T} \mathbf{Q}\, \mathbf{N}_{\mathrm{jump}} + \mathbf{B}_{\mathrm{avg}}^\mathsf{T} (\mathbb{Z} + \mathbb{Y})\, \mathbf{B}_{\mathrm{avg}} + \mathbf{N}_{\mathrm{jump}}^\mathsf{T} \mathbf{H}\, \mathbf{B}_{\mathrm{avg}} + \mathbf{B}_{\mathrm{avg}}^\mathsf{T} \mathbf{H}^\mathsf{T} \mathbf{N}_{\mathrm{jump}} \Big)\, J_0\, w,\]

where \(J_0 = \sqrt{\det \mathbf{G}}\) is the surface Jacobian determinant (\(\mathbf{G}\) is the surface metric), \(w\) the quadrature weight, and \(\sum_{qp}\) the sum over quadrature points. The sign convention is \(\mathbf{K}_e = +\partial \mathbf{P}_e / \partial \mathbf{q}\). The element has no inertia terms.

Elements

Nodes

Description

Two-dimensional interface element between two linear lines (2 bottom and 2 top nodes), Gauss rule gauss( 2 ) (2 points)

IQUAD4

8

Three-dimensional interface element between two bilinear quadrilaterals (4 bottom and 4 top nodes), Gauss rule gauss( 2 ) (2x2 points)

The class is a template in the spatial dimension and the number of nodes. Besides the registered three-dimensional IQUAD4, a two-dimensional instantiation embeds its quadrature-point state in the three-dimensional material layout.

Properties

The interface material is defined by the section: its name is the name of the bulk material and its properties are [E, nu, h, ...], see Interface material (hypoelastic bulk material). The first (optional) element property scales the integration measure \(J_0 w\); it defaults to 1.

State variables

Per quadrature point the element stores, in this order: the force \(\mathbf{t}\), the surface stress \(\mathbf{s}\), the accumulated displacements \([\mathbf{u}^{+}, \mathbf{u}^{-}]\), the accumulated surface strains, followed by the state variables of the interface material (padded for alignment).

Implementation

template<int nDim, int nNodes>
class InterfaceFiniteElement : public Marmot::Discretizations::Elements::Element, public Marmot::Discretizations::Elements::GeometryInterfaceElement<nDim, nNodes>

Inheritance diagram for Marmot::Discretizations::Elements::InterfaceFiniteElement:

Collaboration diagram for Marmot::Discretizations::Elements::InterfaceFiniteElement:

Interface finite element with displacement-jump kinematics.

The element combines geometric interface operators from Marmot::Discretizations::Elements::GeometryInterfaceElement<nDim, nNodes> with an interface-material update (Marmot::Materials::InterfaceMaterialHypoElastic) at each quadrature point. The current formulation uses linearized, small-deformation kinematics. It stores quadrature-point state variables and assembles:

  • element residual vector,

  • algorithmic tangent matrix,

  • zero inertia terms (current formulation).

Template Parameters:

  • nDim – Spatial embedding dimension.

  • nNodes – Number of element nodes.

std::unique_ptr<Material> material

The interface material, constructed once per element.

All quadrature points of an element share one property set, and the material carries no per-quadrature-point state: the state variables are passed in by pointer and the characteristic length is set from QuadraturePoint::characteristicLength before every evaluation. Constructing one instance per quadrature point would repeat the base material’s setup work, which is expensive for LinearViscoElasticWiechert.
