Interface material (hypoelastic bulk material)

Theory

Marmot::Materials::InterfaceMaterialHypoElastic turns any registered hypoelastic bulk material into the constitutive law of a thin interface layer of thickness \(h\). It is the material counterpart of the Interface Finite Element: the element provides the displacement jump and the surface gradient, the material returns the conjugate interface quantities and their tangents.

Kinematics of the layer

For an interface with unit normal \(\mathbf{n}\), jump \([\![\mathbf{u}]\!] = \mathbf{u}^{+} - \mathbf{u}^{-}\) and average surface gradient \(\bar{\nabla}_s \mathbf{u} = \tfrac{1}{2}(\nabla_s \mathbf{u}^{+} + \nabla_s \mathbf{u}^{-})\), the strain of the layer is approximated as

\[\Delta\eps = \operatorname{sym}\Big( \tfrac{1}{h}\, [\![\Delta\mathbf{u}]\!] \otimes \mathbf{n} + \Delta\bar{\nabla}_s \mathbf{u} \Big).\]

This strain increment is passed to the bulk material together with the time increment. The bulk material returns the stress \(\sig\) and its tangent \(\mathbb{C} = \partial\Delta\sig/\partial\Delta\eps\).

Conjugate quantities

The interface returns the traction-like force and the surface stress,

\[\mathbf{t} = \sig\, \mathbf{n}, \qquad \mathbf{s} = h\, \sig,\]

where the surface stress is stored scaled by the thickness \(h\) and unscaled again when it is read back as the bulk stress at the start of the next increment.

Tangents

The bulk tangent \(\mathbb{C}\) is condensed with respect to the normal direction (InterfaceMaterialHelperFunctions::calculateInterfaceMaterialParameters). This yields the four operators \(\hat{\mathbf{Q}}\), \(\hat{\mathbb{Z}}\), \(\hat{\mathbf{H}}\) and \(\hat{\mathbb{Y}}\), which couple the jump and the surface strain to the force and the surface stress. They are scaled with the thickness to the quantities handed to the element:

\[\mathbf{Q} = \tfrac{1}{h}\, \hat{\mathbf{Q}}, \qquad \mathbb{Z} = h\, \hat{\mathbb{Z}}, \qquad \mathbf{H} = \hat{\mathbf{H}}, \qquad \mathbb{Y} = h\, \hat{\mathbb{Y}}.\]

Their roles in the element tangent are described in the Interface Finite Element page.

Properties

The interface material is created with the name of the bulk material and the property array

[ E, nu, h, <remaining properties of the bulk material> ]

that is, the thickness \(h\) is inserted as third entry after \(E\) and \(\nu\), and removed again before the array is passed to the bulk material. For example, the Linear Viscoelastic Wiechert model is used as [E, nu, h, m, n, nMaxwell, minTau, timeToDays]. The state variables of the bulk material are stored in the state-variable block baseMaterialStateVars.

std::tuple<Tensor3333d, const Tensor3333d, Tensor3333d, Tensor33d> interfaceGeometrySystemCouplings(const Tensor33d &N, const Tensor3333d &L)

Computes the geometry-system coupling tensors for an interface.

Forms the contracted matrix \(Q = L:N\) and its inverse \(G\), then computes the coupling tensor \(A = G \otimes N\) and the condensed constitutive tensor \(B = L - L:A:L\).

Parameters:

  • N – [in] Normal projector \(\boldsymbol{n} \otimes \boldsymbol{n}\).

  • L – [in] Fourth-order constitutive tensor.

Returns:

Tuple containing, in order:

  • \(B\): condensed fourth-order constitutive tensor,

  • \(L\): unchanged input constitutive tensor,

  • \(A\): fourth-order geometry-system coupling tensor,

  • \(G = Q^{-1}\): inverse contracted constitutive matrix.

std::tuple<Tensor3333d, Tensor33d, Tensor333d, Tensor3333d> calculateMaterialMatrices(const Tensor3d &normal, const Tensor33d &N, const Tensor3333d &C_nu_aibj)

Computes the four constitutive operators used by an interface material.

Condenses the bulk constitutive tensor with respect to the interface normal direction and derives the operators coupling displacement jumps, surface strains, interface forces, and surface stresses.

Parameters:

  • normal – [in] Unit normal vector of the interface.

  • N – [in] Normal projector \(\boldsymbol{n} \otimes \boldsymbol{n}\).

  • C_nu_aibj – [in] Fourth-order constitutive tensor.

Returns:

Tuple containing, in order:

  • \(Z\): condensed fourth-order surface-strain operator,

  • \(H^{-1}\): second-order displacement-jump operator,

  • \(H^{-1}nF\): third-order jump/surface-strain coupling operator,

  • \(nYH^{-1}Fn\): fourth-order coupling correction.
