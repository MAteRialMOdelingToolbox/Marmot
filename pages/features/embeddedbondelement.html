Embedded Bond Element

Theory

Couples an embedded reinforcement bar (a truss or beam element; only its displacements are coupled) to the host continuum element it lies in by bond-slip. The nodes of the element are the nodes of the bar element, followed by the nodes of the host element (Tri3, Quad4, Quad8, Tetra4, Hexa8, Hexa20: the shapes of the continuum elements in Marmot). The slip is the displacement of the bar relative to the host material point it lies at, in the local frame \(\mathbf{R} = [\mathbf{t}, \mathbf{n}_1, \mathbf{n}_2]\) of the bar axis,

\[\mathbf{s} = \mathbf{R}^\mathsf{T} \Big( \sum_i M_i(\eta)\, \mathbf{u}_i - \sum_a N_a(\boldsymbol{\xi}(\eta))\, \mathbf{u}_a \Big),\]

with the host parent coordinates \(\boldsymbol{\xi}(\eta)\) found by the inverse isoparametric mapping of the host geometry (GeometryElement::parentCoordinates) at initialization. The tangent \(\mathbf{t}\) points from the first to the second end node of the bar element (\(\mathbf{t} = \mathrm{d}\mathbf{X}/\mathrm{d}\eta\)); in 2D, \(\mathbf{n}_1\) is \(\mathbf{t}\) rotated by +90°; in 3D, the normals are an arbitrary right-handed pair that may differ between integration points, so the normal components of slip and bond stress are not comparable between points (the bond-slip laws are isotropic in the normal plane). A bond-slip law gives the bond stress \(\boldsymbol{\tau}(\mathbf{s})\), integrated over the bar perimeter \(p\) and the part \([\eta_s, \eta_e]\) of the bar element inside the host element with a Gauss-Lobatto rule of the quadrature catalogue (gaussLobattoExactToDegree), whose end points sit at the ends of the bar part. The formulation is geometrically linear (reference frame).

Names: EB<nDim>D<nBarNodes><host>, e.g., EB2D2T3, EB2D2Q4, EB2D3Q8, EB3D2H8, EB3D3H20, EB3D2T4.

Element properties: [perimeter, eta_s, eta_e, (number of integration points 2..5)] with \(p > 0\) and \(-1 \le \eta_s < \eta_e \le 1\). They must be assigned before the bond-slip law (the number of integration points sets the number of law instances).

Implementation

template<int nDim, int nBarNodes, int nHostNodes>
class EmbeddedBondElement : public Marmot::Discretizations::Elements::Element

Bond-slip coupling of an embedded reinforcement bar (truss) to the host continuum element it lies in.

The nodes of the element are the nodes of the reinforcement (truss) element, followed by the nodes of the host element (bar first: the element is drawn as its bar; the large-slip element puts the host first, to be drawn as the host on which its channel lies). The reinforcement keeps its own, independent displacement field; the element couples it to the host by the bond stress, which a pluggable bond-slip law (Marmot::Materials::BondSlipLaw) computes from the slip, i.e., the displacement of the bar relative to the host material point it lies at:

\[ \boldsymbol{\Delta}(\eta) = \sum_i M_i(\eta)\, \boldsymbol{u}_i - \sum_a N_a(\boldsymbol{\xi}(\eta))\, \boldsymbol{u}_a , \qquad \boldsymbol{s} = \boldsymbol{R}^T \boldsymbol{\Delta}, \]
with the shape functions \(M_i\) of the bar, \(N_a\) of the host, the host parent coordinates \(\boldsymbol{\xi}(\eta)\) of the bar point \(\eta\) (found by inverse mapping at initialization), and the local frame \(\boldsymbol{R} = [\boldsymbol{t}, \boldsymbol{n}_1, \boldsymbol{n}_2]\) of the bar axis. The internal forces and the tangent are
\[ \boldsymbol{f} = \int \boldsymbol{L}^T \boldsymbol{R}\, \boldsymbol{\tau}\; p\, \mathrm{d}S, \qquad \boldsymbol{K} = \int \boldsymbol{L}^T \boldsymbol{R}\, \frac{\partial \boldsymbol{\tau}}{\partial \boldsymbol{s}}\, \boldsymbol{R}^T \boldsymbol{L}\; p\, \mathrm{d}S \]
with the interpolation operator \(\boldsymbol{L}\) of \(\boldsymbol{\Delta}\) and the bar perimeter \(p\).

One element covers the part \([\eta_s, \eta_e]\) of the bar element that lies inside the host element; a bar element crossing several host elements is coupled by several bond elements. A preprocessor (e.g., the embedded reinforcement generator of EdelweissFE) computes these parts.

The formulation is geometrically linear: the frame is the one of the reference configuration, which is appropriate for small rotations of the bar.

Element properties: [perimeter \(p\), \(\eta_s\), \(\eta_e\), (number of integration points)]. The bond stress is integrated with a Gauss-Lobatto rule (2 to 5 points; default: 2 for linear and 3 for quadratic bars), which places integration points at the ends of the bar part and avoids the traction oscillations of Gauss rules for stiff bond.

Material: a bond-slip law registered in the Marmot::Registry::BondSlipLawFactory.

Template Parameters:

  • nDim – number of spatial dimensions, 2 or 3

  • nBarNodes – number of nodes of the bar element, 2 or 3 (end, end, mid)

  • nHostNodes – number of nodes of the host element (Tri3, Quad4, Quad8, Tetra4, Hexa8, Hexa20; the hosts with a continuum element in Marmot)

Large slip

EmbeddedLargeSlipBondElement lets the bar slide out of (or into) its host element.

Glossary:

  • bar: the 1D elements of one unbranched bar; \(\eta \in [-1, 1]\) is the parameter of a bar element, \(S\) the reference arc length along the bar;

  • window: the consecutive bar elements a bond element may couple to, with the window parameter \(c = k + (\eta + 1)/2 \in [0, n_\mathrm{bar\,elements}]\) in bar element \(k\);

  • channel: the part \([c_s, c_e]\) of the original bar path inside the host element, fixed in the host; the bond history belongs to its points, i.e., to the concrete;

  • channel point: a Gauss-Lobatto point of the channel; its tributary part \([S_a, S_b]\) is the part of the channel its weight represents;

  • partner: the point of the current bar next to a channel point;

  • covered fraction \(x\) of a tributary part, and the fade \(f(x) = 3x^2 - 2x^3\).

It is a point-to-segment contact formulation (Wriggers, Computational Contact Mechanics, 2006, ch. 4; Laursen, Computational Contact and Impact Mechanics, 2002):

bond element

contact mechanics

channel point

slave point

bar window

master segments

partner \(\bar\eta\)

closest point projection

normal gap

tangential slip \(s_t\)

tangential slip in the convected coordinate of the master

Kinematics. The partner of a channel point at \(\mathbf{x}_c\) (moving with the host) solves

\[g(\bar\eta) = \big(\mathbf{x}(\bar\eta) - \mathbf{x}_c\big) \cdot \mathbf{x}_{,\eta}(\bar\eta) = 0\]

on the current bar, extended linearly beyond the window ends; it is searched from the bar element of the previous partner. With the gap \(\mathbf{d} = \mathbf{x}(\bar\eta) - \mathbf{x}_c\) and the current frame \([\mathbf{t}, \mathbf{n}_1, \mathbf{n}_2]\) at the partner (\(\mathbf{t}\) along the current bar, the normals carried from the reference frame by the smallest rotation), the slip is

\[s_t = S_c - S(\bar\eta), \qquad s_{n,i} = \mathbf{n}_i \cdot \mathbf{d}:\]

the reference arc length the bar has slid past the channel point, and the normal gap. \(s_t\) and \(|\mathbf{s}_n|\) are invariant under rigid motions of host and bar; in 2D the element is objective. In 3D the normals follow the bending of the bar but not a rotation about its axis, so under a rigid rotation about an axis not normal to the bar the normal slip components spin about the axis: laws whose normal response depends only on \(|\mathbf{s}_n|\) (linear normal stiffness, Coulomb friction) stay objective, a stored normal history (the plastic normal slip of the MC2010 crushing cap) does not.

Bond and fade. The bar ends move by \(s_t\), so the covered fraction of a tributary part is

\[x = \frac{\min(S_b, S_\mathrm{end} + s_t) - \max(S_a, S_\mathrm{start} + s_t)}{S_b - S_a} \in [0, 1].\]

The bond of the point is scaled by \(f(x)\) (\(C^1\): a kink would make Newton’s method cycle). A channel point the bar has left (\(f = 0\)) has no bond; its slip, bond stress and law history are kept until the bar returns. The bonded length shrinks with the pull-out, up to the smoothing of \(f\) over the tributary part at the bar end: a bar slid by 1 into a channel of length 3 with 3 points is bonded over \(0.5 f(1) + 2 f(0.75) = 2.1875\) instead of 2. For small displacements and a covered channel, the element agrees with the small-slip element to first order (tested entry by entry for forces and tangent).

Residual and tangent. With \(p\,\Delta S\) the perimeter times the tributary length and \(\mathbf{B} = \partial\mathbf{s}/\partial\mathbf{u}\) over the host dofs and the dofs of the partner’s bar element,

\[\mathbf{f} = \sum f\, p\,\Delta S\, \mathbf{B}^T \boldsymbol{\tau}, \qquad \delta\bar\eta = -\frac{(\delta\mathbf{x}_b - \delta\mathbf{x}_c)\cdot\mathbf{x}_{,\eta} + \mathbf{d}\cdot \delta\mathbf{x}_{,\eta}}{\mathbf{x}_{,\eta}\cdot\mathbf{x}_{,\eta} + \mathbf{d}\cdot\mathbf{x}_{,\eta\eta}}, \qquad \delta s_t = -S_{,\eta}\,\delta\bar\eta, \qquad \delta s_{n,i} = \mathbf{n}_i\cdot\delta\mathbf{d} + \mathbf{d}\cdot\delta\mathbf{n}_i .\]

The tangent \(\mathbf{K} = p\,\Delta S \big( f\,\mathbf{B}^T \frac{\partial\boldsymbol{\tau}}{\partial \mathbf{s}}\mathbf{B} + f'\, \frac{\mathrm{d}x}{\mathrm{d}s_t} \mathbf{B}^T\boldsymbol{\tau} \otimes \mathbf{B}_t + f\, \partial(\mathbf{B}^T\boldsymbol{\tau})/\partial\mathbf{u}|_{\boldsymbol{\tau}} \big)\) takes the material part from the algorithmic tangent of the bond-slip law and the fade part analytically; the geometric part (the second derivatives of the projection and the frame, times the bond stress) is the central difference of the analytic \(\mathbf{B}\) over the host and partner dofs only, without evaluating the law. The tests check the whole tangent against central differences of the forces.

Bars and limitations. The bar should be straight or smoothly curved: at a kink, a point on the convex side has the kink node as its partner, its tangential slip stays constant while it is in that wedge (width about \(g\alpha\)), and the slip jumps by about \(2 g \tan(\alpha/2)\) (gap \(g\), kink angle \(\alpha\)) as the point crosses the kink. Rotations of the bar axis near 180 degrees against the reference are not supported. For curved quadratic bars the arc length is integrated numerically, and the tangent is consistent only up to that quadrature error.

Nodes: the host element nodes, followed by the unique nodes of the window in bar order (bar2: e0, e1, ..., eN; bar3: e0, m0, e1, m1, ..., eN). Unlike the small-slip element, the host comes first, so that the element is drawn as its host element (the leading nodes), on which the channel lies.

Names: EBLS<nDim>D<nBarNodes><host>W<nBarElements>, with 1 to 48 bar elements in the window, e.g., EBLS2D2Q4W3, EBLS3D3H20W12. The window is a runtime size of one class per bar and host shape; one name per window size is registered because the element factory takes a function of the element label only. A larger window is an unknown element for the factory.

Element properties: [perimeter, c_s, c_e, start is a bar end, end is a bar end, (number of channel points 2..5)] with \(0 \le c_s < c_e \le n_\mathrm{bar\,elements}\) within one bar element and the flags 0 or 1. If a partner lies beyond an end of the window that is not an end of the bar, the window is too small for the slip and an exception is thrown (EdelweissFE then cuts the increment back, and stops at the minimum increment).

States per channel point: slip, bond stress, elastic energy density and dissipation density (of the law, not faded), dissipation (the faded dissipated energy), partner (window parameter), active (1 while the bar covers the point) and covered fraction (\(x\)).

template<int nDim, int nBarNodes, int nHostNodes>
class EmbeddedLargeSlipBondElement : public Marmot::Discretizations::Elements::Element

Bond-slip of an embedded bar with large slip: the bar may slide out of (or into) its host element.

Glossary.

  • bar: the 1D (truss or beam) elements of one unbranched bar; \(\eta \in [-1, 1]\) is the parameter of a bar element, \(S\) the reference arc length along the bar.

  • window: the nBarElements consecutive bar elements this element may couple to; \(c \in [0, n_{\mathrm{bar\,elements}}]\) is the window parameter, \(c = k + (\eta + 1)/2\) in bar element \(k\) of the window.

  • channel: the part \([c_s, c_e]\) of the original bar path inside the host element, fixed in the host. It owns the bond history: the bond-slip law states belong to the concrete, not to the bar.

  • channel point: an integration point of the channel (Gauss-Lobatto); its tributary part is the part of the channel its weight represents, \([S_a, S_b]\) in reference arc length.

  • partner: the point of the current bar next to a channel point (closest point projection).

  • covered fraction \(x\): the part of the tributary part still covered by the bar; fade \(f(x) = 3 x^2 - 2 x^3\).

Contact mechanics. This is a point-to-segment contact formulation (Wriggers, Computational Contact Mechanics, 2006, ch. 4; Laursen, Computational Contact and Impact Mechanics, 2002): channel point = slave point, window = master segments, partner = closest point projection \(\bar\eta\), normal slip = normal gap, tangential slip = slip in the convected coordinate of the master.

Kinematics. A channel point at \(\boldsymbol{x}_c = \boldsymbol{X}_c + \sum_a N_a \boldsymbol{u}_a\) (host) has its partner at \(\bar\eta\), the solution of the closest point problem

\[ g(\bar\eta) = \big(\boldsymbol{x}(\bar\eta) - \boldsymbol{x}_c\big) \cdot \boldsymbol{x}_{,\eta}(\bar\eta) = 0 \]
on the current bar \(\boldsymbol{x}(\eta) = \sum_b M_b(\eta)\, \boldsymbol{x}_b\), extended linearly beyond the window ends. With the gap \(\boldsymbol{d} = \boldsymbol{x}(\bar\eta) - \boldsymbol{x}_c\) (bar minus host, as in the small-slip element) and the current frame \([\boldsymbol{t}, \boldsymbol{n}_1, \boldsymbol{n}_2]\) at the partner ( \(\boldsymbol{t} = \boldsymbol{x}_{,\eta}/|\boldsymbol{x}_{,\eta}|\), the normals carried along from the reference frame of the channel point, EmbeddedBondKinematics::transportFrame), the slip is
\[ s_t = S_c - S(\bar\eta), \qquad s_{n,i} = \boldsymbol{n}_i \cdot \boldsymbol{d}, \]
the reference arc length the bar has slid past the channel point, and the normal gap. \(s_t\) and the magnitude \(|\boldsymbol{s}_n|\) are invariant under a rigid motion of host and bar. In 2D the element is objective. In 3D the transported normals depend on the tangent only: under a rigid rotation about an axis not normal to the bar they spin about the bar axis relative to the material, so the normal slip components spin too. Laws whose normal response depends only on \(|\boldsymbol{s}_n|\) (linear normal stiffness, Coulomb friction on \(p\)) are unaffected; a stored normal history (the plastic normal slip of the MC2010 crushing cap) is then rotated against the current normal slip, i.e., large 3D rotations with crushing are not objective.

Bond and fade. The tributary part of a channel point is covered by the bar between its ends, which have moved by \(s_t\): \(x = \big(\min(S_b, S_{\mathrm{end}} + s_t) - \max(S_a, S_{\mathrm{start}} + s_t)\big) / (S_b - S_a)\), clamped to [0, 1] (only at bar ends). The bond is scaled by \(f(x)\): \(C^1\), as a kink in the bond force when a bar end leaves a tributary part makes Newton’s method cycle. A channel point the bar has left completely ( \(f = 0\)) has no bond and its history is frozen until the bar comes back. Parts of the bar outside of all channels – e.g., pulled out of the concrete – are unbonded, so the bonded length shrinks with the pull-out, up to the smoothing of \(f\) over the tributary part at the bar end (a bar slid by 1 into a channel of length 3 with 3 points is bonded over \(0.5 f(1) + 2 f(0.75) = 2.1875\) instead of 2). For small displacements and a covered channel, the element agrees with the small-slip EmbeddedBondElement to first order.

Residual and tangent. With \(p\,\Delta S\) the perimeter times the tributary length,

\[ \boldsymbol{f} = \sum_{\mathrm{points}} f\, p\, \Delta S\; \boldsymbol{B}^T \boldsymbol{\tau}, \qquad \boldsymbol{B} = \frac{\partial \boldsymbol{s}}{\partial \boldsymbol{u}}, \]
over the host dofs and the dofs of the partner’s bar element (the work conjugate of the slip). The linearization of the closest point gives
\[ \delta\bar\eta = -\frac{(\delta\boldsymbol{x}_b - \delta\boldsymbol{x}_c) \cdot \boldsymbol{x}_{,\eta} + \boldsymbol{d} \cdot \delta\boldsymbol{x}_{,\eta}}{\boldsymbol{x}_{,\eta} \cdot \boldsymbol{x}_{,\eta} + \boldsymbol{d} \cdot \boldsymbol{x}_{,\eta\eta}}, \qquad \delta s_t = -S_{,\eta}\, \delta\bar\eta, \qquad \delta s_{n,i} = \boldsymbol{n}_i \cdot \delta\boldsymbol{d} + \boldsymbol{d} \cdot \delta\boldsymbol{n}_i \]
( \(\delta\boldsymbol{x}_b, \delta\boldsymbol{x}_{,\eta}\) at fixed \(\eta\)), coded analytically in localKinematics(). The tangent
\[ \boldsymbol{K} = p\,\Delta S \Big( f\, \boldsymbol{B}^T \frac{\partial\boldsymbol{\tau}}{\partial \boldsymbol{s}} \boldsymbol{B} + \frac{\mathrm{d}f}{\mathrm{d}x} \frac{\mathrm{d}x}{\mathrm{d}s_t} \boldsymbol{B}^T \boldsymbol{\tau} \otimes \boldsymbol{B}_t + f\, \frac{\partial (\boldsymbol{B}^T \boldsymbol{\tau})}{\partial \boldsymbol{u}} \Big|_{\boldsymbol{\tau}} \Big) \]
takes the material part from the algorithmic tangent of the bond-slip law, the fade part analytically, and the geometric part (the second derivatives of the closest point projection and of the frame, times the bond stress) by central differences of the analytic \(\boldsymbol{B}\) over the host and partner dofs only (geometry, no law evaluation): geometricStiffness().

Bars and limitations. The bar elements should form a straight or smoothly curved bar: at a kink, the partner of a point on the convex side of the kink is the kink node itself (its projection lies on neither element), its tangential slip stays constant while it is in that wedge (of width about \(g \alpha\), no tangential bond work), and the slip jumps by about \(2 g \tan(\alpha/2)\) for a gap g and a kink angle \(\alpha\) as the point crosses the kink. Rotations of the bar axis near 180 degrees against the reference are not supported (the frame transport degenerates; an exception is thrown at the limit). For curved quadratic bars, the arc length is integrated numerically, so the tangential row of B is consistent with it only up to that quadrature error.

Nodes: the host element nodes, followed by the unique nodes of the window in bar order (bar2: e0, e1, …, eN; bar3: e0, m0, e1, m1, …, eN). Unlike the small-slip element (bar nodes first), the host comes first, so that the element is drawn as its host element (the leading nodes), on which the channel lies.

Element properties: [perimeter, c_s, c_e, start is a bar end, end is a bar end, (number of channel points 2..5)], with \(0 \leq c_s < c_e \leq n_{\mathrm{bar\,elements}}\) within one bar element, and the flags 0 or 1. If the partner of a channel point lies beyond an end of the window that is not an end of the bar, the window is too small for the slip and an exception is thrown.

Material: a bond-slip law registered in the Marmot::Registry::BondSlipLawFactory.

Template Parameters:

  • nDim – number of spatial dimensions, 2 or 3

  • nBarNodes – number of nodes of the bar elements, 2 or 3 (end, end, mid)

  • nHostNodes – number of nodes of the host element (Tri3, Quad4, Quad8, Tetra4, Hexa8, Hexa20)
