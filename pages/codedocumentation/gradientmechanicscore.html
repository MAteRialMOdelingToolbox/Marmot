template<int nNonlocalVariables>
class MaterialGradientEnhancedHypoElastic
#include <MarmotMaterialGeneralGradientEnhancedHypoElastic.h>

Base class for general gradient-enhanced hypoelastic material models.

This class defines the interface for general gradient-enhanced hypoelastic material models, including methods for computing stress, plane stress response, and managing state variables. The template parameter nNonlocalVariables specifies the number of nonlocal variables used in the material model.

In addition to the standard balance of linear momentum each nonlocal variable introduces an additional balance equation, which is solved simultaneously with the balance of linear momentum. This balance equation is defined as:

\[ \knl_i - \nabla ( c( \knl_i )\, \nabla \knl_i ) = s_i (\boldsymbol \varepsilon,\, \knl_i ) \]
where \( \knl_i \) is the nonlocal variable, \( c( \knl_i ) \) is the nonlocal interaction parameter, and \( s_i \) is the local driving variable for the nonlocal variable \( \knl_i \). The interaction parameter \( c( \knl_i ) \) defines the influence of the nonlocal variable on its own gradient and can be used to model phenomena such as damage-dependent interactions. Also phase-field models can be implemented in this framework by defining the nonlocal variable as the phase-field variable and the local driving variable as a function of the strain tensor.

virtual ~MaterialGradientEnhancedHypoElastic() = default

Virtual destructor.

This class is abstract and instances are owned through base-class pointers (e.g. the std::unique_ptr held by the gradient-enhanced elements), so the destructor must be virtual — destroying a derived object through a base pointer with a non-virtual destructor is undefined behaviour. libstdc++ silently invokes the wrong destructor, while libc++/clang diagnoses it (-Wdelete-abstract-non-virtual-dtor) and emits a trap instruction, which aborted every simulation using such a material on macOS/arm64.

inline virtual double getMaximumWaveSpeed(const response &currentResponse, const Eigen::Vector<double, nNonlocalVariables> &K = Eigen::Vector<double, nNonlocalVariables>::Zero()) const

Get the maximum wave speed for the current response state.

The default implementation computes the 3D algorithmic tangent and returns sqrt(max(C_ii) / rho) with C_ii from the Voigt tangent diagonal entries.

Note

The field is passed in because it is an INPUT to the constitutive law, not a state the response carries. Leaving it at zero therefore means “zero”, not “whatever it currently

is” – and where damage is driven by that field alone (

m = 1 in GCDP) that is the virgin tangent however damaged the point is. Pass the current field for the current wave speed; take the default for an undamaged reference or a conservative critical time step.

Note

The default is not cheap: it copies the state and runs the full stress update at a zero strain increment, which on a non-yielding point costs about as much as the stress update itself. That is fine for a critical time step, computed once per step, but the artificial bulk viscosity’s damage degradation asks for the CURRENT wave speed on every quadrature point on every explicit increment, and there the default doubles the material cost. A material whose degraded tangent at a zero strain increment has a closed form – the usual \((1-\omega)\,\mathbb{C}^\mathrm{el}\) of a damage model – should override this with that closed form. The override must return what the default returns for it, must honour K as an input, and must not touch the state. Marmot::Testing::checkMaximumWaveSpeedOverrideMatchesDefault() checks all three against the default.

Parameters:

  • currentResponse – Current response state

  • K – The non-local field values the tangent is to be evaluated at; zero (the default) asks for the response of the material with its non-local field undamaged.

Returns:

Maximum wave speed

inline virtual std::vector<double> getNonlocalMicroInertia(const double *stateVars) const

Get the micro-inertia \(m_k\) of each nonlocal variable.

It multiplies the second time derivative of the nonlocal variable, turning its balance from the parabolic (viscous) equation \( \eta\,\dot{\bar\varepsilon} + \bar\varepsilon - c\,\nabla^2\bar\varepsilon = \tilde\varepsilon \) into the damped hyperbolic one \( m_k\,\ddot{\bar\varepsilon} + \eta\,\dot{\bar\varepsilon} + \bar\varepsilon - c\,\nabla^2\bar\varepsilon = \tilde\varepsilon \), whose stable increment falls off with \(h\) rather than with \(h^2\). The nonlocal viscosity keeps its meaning exactly: what was the coefficient of the highest time derivative becomes the damping.

It sits here, next to getNonlocalViscosity(), because the two are one parameter and not two: the zeroth-order reaction mode does not ring only while \(m_k \le \eta^2/4\), and the largest admissible value is the best one because the stable increment grows with \(\sqrt{m_k}\). Nothing could check that while the two lived at different levels of the stack, and the deck author computed \(\eta^2/4\) by hand; see validatedNonlocalMicroInertia(), which derived classes should return through.

Note

The default is zero for every nonlocal variable, which is the quasi-static model and the behaviour of every material that predates this interface: the field is then first order in time and is integrated by its viscosity alone. A derived class opts in by overriding this, and a run opts in by giving the material the property the override reads – so this is deliberately not pure virtual, unlike getNonlocalViscosity(), which a gradient-enhanced material must answer for any explicit path to exist at all.

Parameters:

stateVars – Pointer to the array of state variables

Returns:

Vector containing the micro-inertia of each nonlocal variable, in seconds squared

inline std::vector<double> validatedNonlocalMicroInertia(std::vector<double> microInertia, const double *stateVars) const

Validate a micro-inertia against this material’s own nonlocal viscosity.

Three failures, each of which is silent without this check:

  • a non-finite micro-inertia passes every ordering test, so a NaN would propagate into the lumped inertia and from there into every increment;

  • a negative one would make the nonlocal field integrate backwards in time;

  • one **above \(\eta^2/4\)** leaves the zeroth-order reaction mode underdamped, so the regularisation rings. That does not present as a failure but as noise on the nonlocal field, which is indistinguishable by eye from the mesh-scale oscillation the gradient enhancement exists to remove.

A viscosity of zero admits no micro-inertia at all: an undamped second-order field rings forever.

Parameters:

  • microInertia – The micro-inertia of each nonlocal variable, as read from the material properties

  • stateVars – Pointer to the array of state variables, to evaluate the nonlocal viscosity at

Throws:

std::invalid_argument – if an entry is non-finite, negative, or exceeds \(\eta^2/4\)

Returns:

microInertia unchanged, if every entry is admissible

template<typename T>
T poh(T omega, double eta, double R)

Damage dependent nonlocal interaction function acc. Poh & Sun (2017).

The function is defined as:

\[ g(\omega) = \frac{(1 - R) \exp(-\eta \, \omega) + R - \exp(-\eta) }{ 1 - \exp(-\eta)} \]
where \( \omega \) is the damage variable, \( \eta \) controls the rate of decrease of interactions with damage, and \( R \) controls the residual interactions at full damage. The function is designed to decrease as damage increases, with a residual interaction value of \( R \) at full damage ( \( \omega = 1 \)).

Parameters:

  • omega – damage variable

  • eta – parameter controlling the rate of decrease of interactions with damage

  • R – parameter controlling the residual interactions at full damage

Template Parameters:

T – type of the interaction function value (e.g., double, dual, etc.)

Returns:

interaction function value

template<int nNonlocalVariables>
void checkMaximumWaveSpeedOverrideMatchesDefault(const Marmot::Materials::MaterialGradientEnhancedHypoElastic<nNonlocalVariables> &material, const typename Marmot::Materials::MaterialGradientEnhancedHypoElastic<nNonlocalVariables>::response &currentResponse, const std::vector<Eigen::Vector<double, nNonlocalVariables>> &fields, double relativeTolerance = 0.0)

Check that an override of getMaximumWaveSpeed() keeps the contract of the base class’ default.

A material overrides getMaximumWaveSpeed() with a closed form to avoid the default’s full constitutive evaluation. The artificial bulk viscosity’s damage degradation divides the wave speed at the current non-local field by the one at a zero field, so an override that ignores the field returns the same speed for both: the ratio is 1 and the degradation silently does nothing. This function compares the override to the default (called non-virtually on the same object) at every given field, and checks that neither touches the state.

Template Parameters:

nNonlocalVariables – Number of non-local variables of the material.

Parameters:

  • material – [in] The material whose override is checked.

  • currentResponse – [in] A response, including its state variables, at which to evaluate both.

  • fields – [in] The non-local fields to evaluate at; they should include fields at which the material is damaged, at least one of them non-zero.

  • relativeTolerance – [in] 0, the default, demands the bits of the default.

Throws:

std::runtime_error – if the override differs from the default or changes the state variables.
